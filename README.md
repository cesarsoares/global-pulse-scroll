# GeoSphere Portal

gostaria de um site/portal que capture noticias do mundo para analistas/estrategistas em geopolitica. o sistema pode criar "balões" segmentados pelos continentes., e a medida em que o scrol desce, são apresentadas noticias mais atuais.
